## Git

Committing and pushing to `main` is authorized whenever work is meant to be shared, findable, or used by another session. Don't ask first. The repo is versioned, so a commit can be rolled back.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `enduring-game-standard/maps-notation`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context. The glossary is `GLOSSARY.md` at the repo root; wherever a skill says `CONTEXT.md`, use `GLOSSARY.md`. See `docs/agents/domain.md`.
