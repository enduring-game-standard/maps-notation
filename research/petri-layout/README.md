# Petri net placement rules

Placement rules reverse-engineered from the figures in J. L. Peterson, *Petri Net Theory and the Modeling of Systems* (Prentice-Hall, 1981), and a layout engine that applies them to nets given without coordinates.

Start with `FINDINGS.md` for the results and `RULES.md` for the rules.

Images and the source PDF are not committed. `tools/` regenerates the figure clips from a local copy of the PDF.
