# ovl_En_Bili

Reviewer: Claude Sonnet 5.5

## Verdict

major findings

## Findings

1. **Missing `backlash` (spec level, plus `stunned` needs `backlashOff`).** Severity: major (changes what hurts Link). The hurtbox element is `{ 0xFFCFFFFF, HIT_BACKLASH_ELECTRIC, 0 }` at `src/overlays/actors/ovl_En_Bili/z_en_bili.c:66`, and `EnBili_SetupIdle` sets `hitBacklash = HIT_BACKLASH_ELECTRIC` again at line 151. Collision copies it onto the attacker (`src/code/z_collision_check.c:1732`), and the player code then deals 8 damage with `PLAYER_HIT_RESPONSE_ELECTRIFIED` to any melee-weapon hit except the hammer (`src/overlays/actors/ovl_player_actor/z_player.c:9139-9150`). The spec has no `backlash` field and no backlash attack, though other specs use one (for example `studio/tools/ocarina/data/actors/en_bx.ts:16`). Slashing, spinning, jumping, or poking a Biri shocks Link, including the killing hit. The backlash is off only while stunned: `EnBili_SetupStunned` sets `HIT_BACKLASH_NONE` at line 233, and `EnBili_SetupIdle` restores it at 151 (so `stunned` takes `backlashOff: at(233)`).
2. **Reaction `EN_BILI_DMG_REACT_SWORD_SLASH` (`damage.reactions`, cite `at(526)`).** The spec note says the Biri "electrifies and then dies", but the model ends the fight on the slash. In the code a slash that empties health sets `params = EN_BILI_TYPE_DIE_AFTER_ELECTRIFY` and calls `EnBili_SetupElectrify` (`z_en_bili.c:525-528`). `SetupElectrify` does not clear `AT_ON` (171-177), and the AT is submitted every frame (579-580), so a contact during the 10-frame electrify re-runs `SetupElectrify` (553-555). Only when the timer runs out does it go to `EnBili_SetupDie` (363-365). Severity: minor (a Biri killed by a sword can still shock a Link who stands in reach for about a beat; the author named the electrify but dropped the consequence).
3. **Missing transitions into `electrify` from `idle` and `flee` (steps).** The spec's only AT transition is `approach -> electrify` (cite 555). The code runs `if (this->collider.base.atFlags & AT_HIT) { ... EnBili_SetupElectrify(this); }` at lines 553-556 before any action function, from every phase whose AT is on. `SetupIdle` turns AT on (156) and `SetupFleePlayer` turns it on (197), so `idle` and `flee` (and `knockback`, which never clears it, 201-209) can all zap Link; only `ascend` (181), `stunned` (238), `spawned` (167), and the dying states have it off. Severity: minor (in the model Link must wait one beat while the Biri goes `idle -> approach` before it can shock him).
4. **Phase `ascend` has no `frames` and step `ascend -> flee` ("Biri is up") has no `afterTimer`.** The code leaves `EnBili_AscendAway` only when the animation finishes (`if (animFinished) EnBili_SetupFleePlayer`, line 383-384). `gBiriAscendAwayAnim` frame count is not in this checkout (the tentacle-texture code at 273-288 suggests about 40 frames), so I cannot state the beat count. Severity: minor (timing; the spec treats it as one beat).

## Outcomes
1. fixed: added `backlash: { attack: 'backlash', cite: z_en_bili.c:66 }` and the 8-damage unblockable, undodgeable `backlash` shock (source the hurtbox element, line 65). `stunned` is `backlashOff: at(233)`. Every connecting melee hit outside the stun now shocks Link, the killing hit included.
2. fixed: the slash reaction now sends an awake Biri to a new `electrify_dying` phase (10 frames, line 173; cite 526) instead of draining the pool, and a stunned one to `defeated` (line 530). `electrify_dying` re-zaps a near Link (555) and goes to `defeated` after its timer (365). Melee hits on it deal 0 (CheckCollide skips at health 0, line 510) but still shock, since collision copies the backlash regardless (z_collision_check.c:1732). The slash reaction is `damage: false` because the kill is the move: every slash deals at least 1 against 1 health (lines 94-96, 74).
3. fixed: added near zap steps `idle -> electrify`, `flee -> electrify`, `knockback -> electrify`, and the self-step `electrify -> electrify` (all line 555). AT is on in idle (156), flee (197), knockback (never cleared), and electrify (not cleared, 171-177).
4. gap: `gBiriAscendAwayAnim` has only an offset in this checkout (assets/xml/objects/object_bl.xml:4) and no extracted frame data, so `ascend` cannot get a cited timer. Recorded in the spec header.
