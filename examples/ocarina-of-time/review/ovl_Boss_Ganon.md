# ovl_Boss_Ganon

Reviewer: Claude Sonnet 5.5 (claude-sonnet-5-5)

Spec: `studio/tools/ocarina/data/actors/boss_ganon.ts`. Code: `src/overlays/actors/ovl_Boss_Ganon/z_boss_ganon.c` (cites below are in that file unless a path is given).

## Verdict

major findings

## Findings

1. **major** - `pound_*` steps (`body` on `range: near`, `shockwave` on `range: far`). The spec splits the landing hurt by Link's range: near gets `body` (16, blockable), far gets `shockwave` (32). The code does not split them. The shockwave effect spawns on every landing at Ganon's ground position (`z_boss_ganon.c:1996-2007`, `unk_19C == 35` set at 1943). It hurts any grounded Link (`fabsf(player y) < 5`) whose distance `d` from the landing point satisfies `scale*150 < d < scale*300` (4800-4807). Scale starts at 0 (2007) and grows 0.13 per frame (4798), and the effect dies when alpha drops below 0 at 30 per frame (4791-4795), about 9 frames. The ring therefore sweeps every grounded `d` from about 20 to about 350, which covers all of the central square that the spec calls near. So a near Link takes the 32-damage shockwave, not 16. The body cylinder only matters when Link overlaps Ganon's cylinder (radius 20, 97-98 and 128). A far Link beyond about 350 units takes nothing. Fix: near and far should both deliver `shockwave`; `body` is an extra only for contact. Whether far-beyond-350 exists in the model is the author's call.
2. **major** - `magic_out_*` overrides (`BALL_SWINGS` to `stunned_*`, cite 4449) and `big_magic.reflect` (Mirror Shield to `MIR_RAY`, cite 4449). The spec says any swing, and the Mirror Shield, returns the big magic to Ganondorf and stuns him (summary and `stunned_*`). The code aims the ball at Ganondorf only for a spin attack: `meleeWeaponState != 0`, `meleeWeaponAnimation >= PLAYER_MWA_SPIN_ATTACK_1H`, ball within 80 of Link (4433-4440, target `dorf->unk_1FC`). Every other deflection, the Mirror Shield included (the branch at 4444-4449 accepts any non-shield hit or the Mirror Shield), picks a random point within +/-350 in x and z and +/-100 in y of Ganondorf (4457-4463) and flies toward it. Ganondorf is stunned only if the ball ends within 45 of him (4528-4529). Otherwise the ball leaves the arena and spawns a 0x190 burst with no effect on Ganondorf (4541-4549). So a slash, jump or hammer hit, or the Mirror Shield, is a gamble, and only the spin is a sure stun. The model makes all of them a sure stun, which overstates how easily Link wins the lo and fl bands. Fix: guarantee only for the spin attacks; give the others a miss branch (no stun).
3. **minor** - `actionFuncs`: `BossGanon_Vulnerable` and `BossGanon_Damaged` both map to `downed_*` only. `BossGanon_Vulnerable` is also the fall (`unk_1C2` 0-2, 2580-2610) and the get-up (cases 5-8, 2645-2697), so it is `falling_*` and `rising_*` too. `BossGanon_Damaged` is entered from a hit in rising too (UpdateDamage accepts `unk_1C2 >= 3`, 2743, and Damaged sets case 4 at 2720, which re-enters the get-up when timer 0 is spent). No ledger key maps to `falling_*` or `rising_*`.
4. **minor** - `ball_back_*` weights 7 and 3 (cites 3991, 4138). The 0.7 draw (3991) only applies in some cases. If Ganondorf is more than 250 units from Link and the ball has been hit fewer than 3 times, the volley is forced (`unk_1C2 = 1`, 3989-3990). The ball-hit count `unk_1A4` (3982) is not in the model. Link at long range can count on at least 3 returns, not 70/30 each time.
5. **minor** - `wait_lo`/`wait_fl` far steps, weights 2/1/1 (cites 2258, 2260, 2263). The big magic is also chosen whenever `xzDistToPlayer > 350` (2257), so the pound's odds fall and the big magic's rise with distance. The 2/1/1 weights match only for distances at or under 350.
6. **minor** - `ball_out_* -> wait_*` after the ball hits Link (cite 4140). When the ball hits Link (`spBA == 5`) Ganondorf's wait timer is set to 125 frames (4142-4143), about 6 beats, not the 30-93 range of `wait_*.frames` (2227). The shield-block and miss paths use the normal range.
7. **minor** - `block_*` has no step on a repeat shot. In `block_*`, Link firing again (`unk_A73 != 0`) re-runs `SetupBlock` (2875-2877), which resets the timer to 10 (2410) and restarts the block animation if Ganondorf was releasing (2402). The block can be extended; the spec has no `block_x -> block_x`.
8. **minor** - `ball_out_*` hits. The ball can also be hit by a bottle swing within 25 units while facing Ganondorf (`hitWithBottle`, 3959-3966), which sends it back with a 0.9/0.1 draw (4002-4007). No DMG type, so the types cannot express it; the spec does not mention it.
9. **minor** - `downed_*`/`rising_*` hits during the Damaged animation. UpdateDamage damages only when `actionFunc == BossGanon_Vulnerable` (2743), so hits during `BossGanon_Damaged` (2708-2724) are ignored. The model lets every beat's hit connect.
10. **minor** - step cites that show a side effect, not the transition. `charge_* -> ball_out_*` cites 2372 (the ball spawn); the action change is `BossGanon_SetupPlayTennis` at 2318. `magic_hold_* -> magic_out_*` cites 2192 (the spawn in case 4); the case change is 2179.

## Outcomes
1. fixed: near and far pound landings both deliver `shockwave` (z_boss_ganon.c:4806). The ring sweeps 150-300 x scale as scale grows 0.13 a frame for about 9 frames (4791-4804), which covers the 110-unit near box (2248-2249). `body` moved to a near step out of `pound_end_*` (Ganondorf sits at y 60 for 10 frames, 1939-1941, with his collider AT, 2917-2919). The narrow spot right under the landing, where the ring misses and only the body touches, is recorded in the spec header.
2. fixed: in `magic_out_*` only `SPIN_MASTER` and `SPIN_GIANT` stun (4433-4439). The other ball swings send Ganondorf to `wait_*` with no stun (4457-4463). The Mirror Shield reflect no longer stuns: the `MIR_RAY` override is gone from `wait_*`, so the reflected ball has no effect. Ledgered `miss_reflect_big_magic` is removed because it is now live. The small geometric chance that a deflected ball still passes within 45 (4528) has no coded odds. It is a gap, recorded in the header.
3. fixed: `falling_*`, `downed_*` and `rising_*` are renamed `down_falling_*`, `down_lying_*` and `down_rising_*`. `BossGanon_Vulnerable` maps to `down_*` and `BossGanon_Damaged` to `down_lying_*`. Also found: the get-up sets `unk_2D4 = 80` (2633), and AC is registered only while it is 0 (2914). So `down_rising_*` is now `hittable: 'none'`, and its threshold entries and `body_empty_in_rising_hi` are dropped.
4. answered: a return is a melee swing, which the beat model allows only to a near Link. Near is inside the 110-unit box (2248-2249) with Ganondorf floating near y 150 (2272), so Link is almost always within 250 of him and the 0.7 draw (3991) is what applies. A return from beyond 250, which forces the volley (3989), is not representable. That is recorded in the header.
5. gap: the >350 big-magic rule (2257) needs a third range band. Recorded in the header.
6. fixed: the light ball hitting Link goes to a new `wait_hit_*` phase with a 125-frame timer (4142-4143) and the same hits and steps as `wait_*`.
7. gap: a refire during a block resets the block timer (2877, 2410), but a phase re-entering itself keeps its timer in the generator. Recorded in the header.
8. gap: a bottle swing is not a damage type, so the 0.9/0.1 bottle return (3959-3966, 4002-4007) is not expressible. Recorded in the header.
9. gap: a damaged phase would restart the 70-frame down timer (2607), which keeps running through `BossGanon_Damaged` in the code (2718-2720). The damage animation's length is in the object binary. Recorded in the header.
10. fixed: `charge_* -> ball_out_*` now cites 2318 and `magic_hold_* -> magic_out_*` cites 2179.
